Flujo del sistema

      
Cámara/imagen → escala de grises → umbral → segmentación → 28×28 → normalización → red neuronal → resultado.

      
Para texto, el sistema separa líneas y caracteres, clasifica cada letra con EMNIST y reconstruye palabras y frases.
